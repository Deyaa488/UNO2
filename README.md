# 🎴 UNO 3D — تطبيق الهاتف المستقل (LAN Peer-to-Peer & Offline Solo)

لعبة **أونو ثلاثية الأبعاد (Three.js)** تعمل بالكامل على **هواتف أندرويد فقط** بدون حاسوب، بدون تيرمينال، وبدون إنترنت!

---

## 🌟 المعمارية المعتمدة للعب بين الهواتف مباشرة (P2P LAN)

1. **سيرفر أندرويد أصلي مدمج (Native Embedded WebSocket Server):**
   - هاتف المضيف (Host) يشغل سيرفر WebSocket خفيف جداً ومكتوب بلغة **Java نقية** (`org.java-websocket:Java-WebSocket:1.5.6`) في خلفية التطبيق مباشرة بمجرد الضغط على إنشاء لعبة.
   - لا حاجة لـ Node.js أو حاسوب أو أي بيئة خارجية.

2. **الاكتشاف التلقائي عبر بروتوكول أندرويد الرسمي (Network Service Discovery - NSD/mDNS):**
   - هاتف المضيف يعلن عن وجود اللعبة على الشبكة المحلية باسم الخدمة `_uno3d._tcp`.
   - هواتف الأصدقاء تبحث وتكتشف هاتف المضيف وتلتقط عنوان الـ IP والمنفذ تلقائياً في ثوانٍ معدودة.
   - **النتيجة:** لا كتابة IP، لا تعقيدات، انضمام فوري بنقرة زر واحدة.

3. **صلاحيات أندرويد وقفل الـ Multicast (MulticastLock):**
   - تم تضمين صلاحية `CHANGE_WIFI_MULTICAST_STATE` و `ACCESS_WIFI_STATE` لضمان فك حظر حزم الـ mDNS على أجهزة سامسونج وشاومي وهواوي التي تعطلها افتراضياً لتوفير البطارية.
   - تم تفعيل `FLAG_KEEP_SCREEN_ON` أثناء اللعب حتى لا تنطفئ الشاشة ويوقف النظام الاتصالات أثناء الجولة.

## 🧪 مرحلة النموذج التجريبي (Milestone 1: Prototype Test)

للتأكد 100% من نجاح التواصل بين هاتفين حقيقيين عبر الـ APK قبل أي شيء آخر:
1. ثبت نفس الـ APK على هاتفين متصلين بنفس الواي فاي (أو أحدهما مشغل نقطة اتصال Hotspot والآخر متصل بها).
2. افتح التطبيق في الهاتفين واضغط على **"🔬 تجربة الاتصال المباشر بين هاتفين (P2P Prototype)"**.
3. **في الهاتف الأول (المضيف):** اضغط `🚀 تشغيل السيرفر والإعلان عبر NSD`.
   - سيعرض الهاتف عنوان الـ IP المحلي ويبدأ بث الخدمة.
4. **في الهاتف الثاني (المنضم):** اضغط `🔍 اكتشاف هاتف المضيف واختبار الاتصال`.
   - سيكتشف الهاتف الثاني هاتف المضيف تلقائياً، ويفتح معه اتصال WebSocket تجريبي، ويرسل رسالة `PING` ويستلم `PONG`.
   - تظهر رسالة نجاح تؤكد أن الهاتفين يتحدثان معاً محلياً 100%!

## 📱 بناء الـ APK عبر GitHub Actions

كل شيء مبرمج ليعمل تلقائياً:
1. ارفع المشروع إلى مستودعك على GitHub (`git push`).
2. يقوم ملف `.github/workflows/build-apk.yml` تلقائياً بـ:
   - تهيئة بيئة Capacitor لنظام أندرويد.
   - نسخ إضافة الجافا المدمجة (`android-plugin/`).
   - إضافة مكتبة `Java-WebSocket` إلى ملف Gradle.
   - إضافة صلاحيات الشبكة والـ Multicast في `AndroidManifest.xml`.
   - تفعيل `usesCleartextTraffic="true"`.
   - بناء ملف الـ APK النهائي وإتاحته للتنزيل من قسم **Artifacts**.
