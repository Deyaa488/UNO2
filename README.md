# 🎴 UNO 3D — تطبيق الهاتف المستقل (LAN Peer-to-Peer & Offline Solo)

لعبة **أونو ثلاثية الأبعاد (Three.js)** تعمل بالكامل على **هواتف أندرويد فقط** بدون حاسوب، بدون تيرمينال، وبدون إنترنت!

---

## 🌟 المعمارية المستقلة (هواتف أندرويد فقط)

1. **سيرفر أندرويد أصلي مدمج (Native Embedded WebSocket Server):**
   - هاتف المضيف (Host) يشغل سيرفر WebSocket خفيف جداً ومكتوب بلغة **Java نقية** (`org.java-websocket:Java-WebSocket:1.5.6`) في خلفية التطبيق مباشرة بمجرد الضغط على "إنشاء لعبة".
   - لا حاجة لـ Node.js أو حاسوب أو أي بيئة خارجية.

2. **الاكتشاف التلقائي عبر بروتوكول أندرويد الرسمي (Network Service Discovery - NSD/mDNS):**
   - هاتف المضيف يعلن عن وجود اللعبة على الشبكة المحلية باسم الخدمة `_uno3d._tcp`.
   - هواتف الأصدقاء تبحث وتكتشف هاتف المضيف وتلتقط عنوان الـ IP والمنفذ تلقائياً في ثوانٍ معدودة.
   - **النتيجة:** لا كتابة IP، لا إعدادات تقنية، انضمام فوري بنقرة زر واحدة.

3. **منطق اللعبة الكامل (108 كرت + كل القوانين الرسمية):**
   - يعمل محرك اللعبة في هاتف المضيف لإدارة الكروت، الخلط، الأدوار، الاتجاه، كروت Skip/Reverse/+2/Wild/+4، تعويض المنقطع ببوت، وطرد اللاعبين.
   - تم تصحيح اختيار ألوان Wild لضمان مطابقة المقاعد بدون أي تجميد.

4. **نظام الجودة السلس (Live Quality Switching):**
   - الجودة الافتراضية هي **متوسطة (Medium)** لضمان السلاسة على مختلف الهواتف.
   - يتم تبديل الجودة فورياً داخل المشهد دون إعادة تشغيل الصفحة (`location.reload()`) ودون مقاطعة اللعب.
   - الكروت تبقى حادة وواضحة ومقروءة 100% في جميع المستويات (Low, Medium, High).

5. **زر الرجوع الذكي (Hardware Back Button):**
   - مدعوم رسمياً عبر `@capacitor/app`.
   - يغلق النوافذ المنبثقة، يعود للشاشات السابقة في اللوبي، ويعرض تأكيد مغادرة أثناء الجولة الجارية.

---

## 🎮 طريقة اللعب

1. ثبت نفس ملف الـ APK على هواتف الأصدقاء.
2. اتصلوا جميعاً بنفس شبكة الواي فاي (أو يشغل أحدكم نقطة اتصال **Mobile Hotspot** من هاتفه ويتصل البقية بها بدون رصيد إنترنت).
3. **اللاعب الأول:** يضغط **"🎮 إنشاء لعبة (Host)"** ويختار اسم الغرفة.
4. **بقية اللاعبين:** يضغطون **"🔍 بحث عن لعبة قريبة (Join)"**، تظهر الغرفة فوراً، يضغطون عليها ويدخلون.
5. يضغط المضيف **"▶️ ابدأ اللعبة الآن"** وتبدأ الجولة ثلاثية الأبعاد!

---

## 📱 بناء الـ APK عبر GitHub Actions

1. ارفع المشروع إلى مستودعك على GitHub (`git push`).
2. يقوم ملف `.github/workflows/build-apk.yml` تلقائياً بـ:
   - تهيئة بيئة Capacitor لنظام أندرويد.
   - نسخ إضافة الجافا المدمجة (`android-plugin/`).
   - حقن مكتبة `Java-WebSocket` في Gradle والصلاحيات في `AndroidManifest.xml`.
   - بناء ملف الـ APK النهائي وإتاحته للتنزيل من قسم **Artifacts**.
